## What is GHM-M?

**GHM-M** (Gear Heart Methodology for Methodologies) is a variant of GHM adapted for developing methodologies, frameworks, and documentation systems—not software products.

**Key Adaptations:**
- **MRD** instead of PRD (Methodology Requirements Document)
- **Practitioners** instead of users
- **Patterns** instead of APIs
- **Templates** instead of schemas
- **Validation** (case studies) instead of tests
- **Publication** instead of deployment

**Core Preserved:**
- 3+1+SoT+Temp documentation stack
- ID-based knowledge graph
- Session protocols for continuity
- Progressive lifecycle (v0.1 → v1.0)
