# Adapted Skills (GHM + Team Extensions)

**Purpose:** GHM skills extended for multi-disciplinary team collaboration and enterprise requirements.

## Adaptation Strategy

### Core Principle
**Extend, don't replace** - Keep GHM skill functionality while adding:
- **Team coordination** capabilities
- **Role-specific context** management
- **Enterprise compliance** features
- **Cross-discipline handoffs**

### Adaptation Pattern
```
team-skill-name/
├── SKILL.md              # Team-adapted version
├── ghm-base/             # Link to original GHM skill
├── team-extensions/      # Team-specific additions
│   ├── multi-discipline.md
│   ├── enterprise-security.md
│   └── coordination.md
└── examples/             # Team workflow examples
```

## Team Extensions

### Multi-Discipline Support
- **Shared context** management across PM, Designer, Developer
- **Role-specific views** of same underlying information
- **Cross-references** between discipline contexts

### Enterprise Features
- **IBM security compliance** integration
- **Approval workflows** for sensitive changes
- **Audit trails** for enterprise governance
- **Integration points** with IBM tools

### Coordination Capabilities
- **Handoff protocols** between team members
- **Conflict resolution** for overlapping changes
- **Status synchronization** across team contexts
- **Notification systems** for context updates

## Usage

Adapted skills work like GHM skills but with team-aware features:
- **Individual mode** - Works like original GHM skill
- **Team mode** - Adds coordination and sharing capabilities
- **Enterprise mode** - Includes compliance and security features

## Development Process

1. **Start with imported GHM skill** as base functionality
2. **Identify team gaps** in original design
3. **Design extensions** that don't break core workflow
4. **Test with multi-person teams** 
5. **Document team-specific features**
6. **Update when GHM base skill changes**
